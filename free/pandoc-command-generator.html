Questions
How do I convert Word to Markdown?
Put your .docx file as the input and choose “Markdown” as the output. Pandoc reads the input format from the file extension.
Can it make a PDF?
Pandoc needs a separate PDF engine (LaTeX or Typst) for PDF output, so this generator sticks to formats that work with Pandoc alone. Make a .docx and save it as PDF from Word, or use Typst.
Are these the right options for my version?
They are the commands GUI Hub itself runs, and every option is checked against the real Pandoc 3.14 help output on Windows, macOS and Linux in our automated tests.
Do I need to install anything?
Only Pandoc itself (pandoc.org/installing, or winget install JohnMacFarlane.Pandoc / brew install pandoc / your Linux package manager). This page just writes the command; nothing is uploaded. If you’d rather not use a terminal, the GUI Hub desktop app runs the same commands from a form, offline, and its MCP server lets Claude or Cursor run them for you.
Windows: why do the quotes look different?
cmd and PowerShell don’t understand single quotes, so the Windows version wraps arguments with spaces in double quotes. Pick your system above the command.
