DuckDB command generator

Convert CSV ↔ Excel, Parquet and JSON, merge many CSV files (columns matched by name), remove duplicate rows, or look inside a big file — one duckdb command, no database to set up.

Common DuckDB commands
Look inside a file
See the columns, a preview of the first rows, and per-column stats (types, empty cells, min/max, unique values) of any CSV, Excel, Parquet or JSON file — even huge ones.
duckdb -markdown -c 'SELECT * FROM '\''data.csv'\'' LIMIT 10; SUMMARIZE SELECT * FROM '\''data.csv'\'';'
Convert
Turn CSV into Excel, Excel into CSV, or either into Parquet or JSON.
duckdb -cmd 'INSTALL excel; LOAD excel;' -c 'COPY (SELECT * FROM '\''data.csv'\'') TO '\''output.xlsx'\'' (FORMAT xlsx, HEADER true);'
Combine files
Stack many CSV files (e.g. monthly exports) into one table. Columns are matched by name, so files with different column orders still line up.
duckdb -cmd 'INSTALL excel; LOAD excel;' -c 'COPY (SELECT * FROM read_csv(['\''jan.csv'\'', '\''feb.csv'\''], union_by_name = true)) TO '\''output.xlsx'\'' (FORMAT xlsx, HEADER true);'
Remove duplicates
Save a copy with exact duplicate rows removed.
duckdb -cmd 'INSTALL excel; LOAD excel;' -c 'COPY (SELECT DISTINCT * FROM '\''data.csv'\'') TO '\''output.xlsx'\'' (FORMAT xlsx, HEADER true);'
Ask with SQL
Answer questions about your data with SQL — totals, filters, joins across files. Refer to files by path in single quotes, e.g. SELECT region, sum(amount) FROM '/path/sales.csv' GROUP BY region.
duckdb -markdown -cmd '.maxrows 100' -c 'SELECT region, sum(amount) FROM '\''sales.csv'\'' GROUP BY region'



Questions
Why does the Excel command start with INSTALL excel?
Writing .xlsx needs DuckDB’s excel extension; the first run downloads it once, after that it works offline.
How big a file can it handle?
DuckDB streams the data, so CSV files of many gigabytes work on an ordinary laptop.
Are these the right options for my version?
They are the commands GUI Hub itself runs, and every option is checked against the real DuckDB 2.0.0 help output on Windows, macOS and Linux in our automated tests.
Do I need to install anything?
Only DuckDB itself (duckdb.org/docs/installation (single file), or winget install DuckDB.cli / brew install duckdb). This page just writes the command; nothing is uploaded. If you’d rather not use a terminal, the GUI Hub desktop app runs the same commands from a form, offline, and its MCP server lets Claude or Cursor run them for you.
Windows: why do the quotes look different?
cmd and PowerShell don’t understand single quotes, so the Windows version wraps arguments with spaces in double quotes. Pick your system above the command.
