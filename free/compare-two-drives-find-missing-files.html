Find files on Drive A that aren’t on Drive B

Before you wipe an old drive, check that every file on it already exists somewhere on your new drive or NAS — even if you reorganised the folders since. Pick the two folders or drives; you get the list of files that have no copy on the other side, and a CSV to download. Nothing is uploaded or changed.

How it works

It lists every file under A and B. In name + size mode, a file on A counts as copied if a file with the same name and size exists anywhere on B. In content mode, it compares the actual contents (xxHash64) of files whose sizes match, so renamed or moved copies count too — and a same-named file with different contents does not. Folder structure never matters.

Questions

Does this change or delete anything?

No. It only reads file names, sizes and (in content mode) file contents to compare them. Nothing is moved, deleted or uploaded — it all runs in this browser tab.

Name + size or content — which should I use?

Name + size is instant and fine when you copied files without renaming them. Content compares the actual bytes (xxHash64), so it also finds copies that were renamed or moved, and catches files with the same name and size but different contents. It only reads files whose size also appears on the other drive, so it is much faster than hashing everything.

Can it compare a drive with a NAS?

Yes, if the NAS folder is mapped as a drive letter or network folder you can choose in the folder picker. Content mode then reads the files over the network, which takes longer.

Which browsers work?

Chrome and Edge let you pick a whole drive or folder directly. Other browsers use a folder upload dialog — the files still stay on your computer. Some browsers do not allow picking the root of the system drive (C:\); pick a folder inside it instead.
