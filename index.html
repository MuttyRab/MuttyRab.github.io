Questions

Is this made by the authors of these tools?
No. GUI Hub is an independent, unofficial interface. The tools are open source and you can always use them directly from the command line for free.
Do my files get uploaded anywhere?
No. Tools run locally. Only tools whose job is network transfer (like sending files) use the network.
My Mac says the app “can’t be opened” or is from an unidentified developer.
Open the app once, then go to System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do this the first time.
Windows shows “Windows protected your PC”.
Click More info, then Run anyway. This appears for new apps that haven’t built up a download history yet.
