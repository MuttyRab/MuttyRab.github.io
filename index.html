Built for MCP from the start

Most MCP servers do one thing and need Node or Python, a config file and sometimes an API key. GUI Hub is one desktop install (no account, no runtime to set up) that exposes every tool to any MCP client:

  • One click to connect Claude Desktop or Cursor; copyable settings for everything else.
  • Typed tools with clear parameters (e.g. pdfcpu_merge, ffmpeg_gif, f2_rename), generated from the same forms you see in the app.
  • Local and private: your assistant runs the real programs on your machine.
  • Safe defaults: renames preview first, uploads dry-run first, outputs never overwrite originals unless asked.

Installing

As a new publisher, the first launch shows an operating-system caution. Here’s how to continue:

Windows

  1. Download and open the installer.
  2. On “Windows protected your PC”, click More info → Run anyway.
  3. It installs and opens.

macOS

  1. Download (Intel), drag the app to Applications.
  2. Open it; if macOS can’t verify it, click Done.
  3. System Settings → Privacy & Security → Open Anyway.

Linux

  1. Download the AppImage.
  2. Make it executable (Properties → Permissions).
  3. Run it.

Questions

What is GUI Hub, exactly?

A desktop app for Windows, macOS and Linux. Inside are simple forms for well-known open-source command-line programs: FFmpeg for video, pdfcpu for PDFs, F2 for renaming files, croc for sending files and immich-go for importing photos. You choose files and options; the app runs the real program for you.

What is MCP and why would I want it?

MCP (Model Context Protocol) is the standard way AI assistants such as Claude Desktop, Cursor, VS Code and Windsurf use tools on your computer. GUI Hub includes an MCP server, so you can ask your assistant to “compress these videos” or “merge these PDFs” and it runs the same tools locally. Connecting takes one click in the app.

Is it private?

Yes. Files are processed on your own computer; nothing is uploaded to us and there is no telemetry. Only tools whose job is networking (sending a file, uploading to your own Immich server) use the internet.

How does the free version work?

Send Big Files is free without limits. Every other tool works fully three times, in the app or through your AI, so you can check it does what you need. $19 once unlocks everything.

Is it a subscription?

No. Pay once and keep it, including tools added later, on up to 3 computers. 30-day money-back guarantee.

Why not use the command-line tools directly?

You can — they are free and excellent, and we credit them on every page. GUI Hub is for when you don’t want to learn flags, or want your AI assistant to do it without installing Node, Python or separate MCP servers for each tool.

Which exact programs does it run?

Official releases of each project, pinned to a specific version and verified with a SHA-256 checksum before first use. Each tool page lists the program, version and license.

Why does Windows or macOS warn me when installing?

We are a new, small publisher, so the operating system shows a one-time caution. The installing section shows how to continue.
