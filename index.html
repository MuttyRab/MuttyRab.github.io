01 — The problem

Your AI can write the ffmpeg command. It can’t run it.

Ask an assistant to shrink a video or turn a Word file into Markdown and you get a wall of flags to paste into a terminal — or a suggestion to upload your file to some website. The tools that do these jobs best are free and open source, but they were built for people who live in a command line.

Setting them up as MCP servers usually means Node, Python, config files and one server per tool.

A desktop app (Windows, macOS, Linux) with simple forms for 8 open-source tools — Image Compressor (Caesium), Send Big Files (croc), Rename Many Files (F2), Video Toolkit (FFmpeg), Google Photos → Immich (immich-go), Document Converter (Pandoc), PDF Toolkit (pdfcpu), PDF Maker (Typst) — and a built-in MCP server that gives Claude, Cursor and other assistants the same 24 tools.

What is MCP?

Model Context Protocol: the standard way AI assistants such as Claude Desktop, Cursor, VS Code and Windsurf call tools on your computer. Without it, your assistant can only tell you a command. With it, the assistant runs the job.

Why not just use the free command-line tools?

You can, and we credit them on every page. You are paying for not having to learn their flags, for one install instead of six, for a verified copy of each program, and for an AI connection that works in one click instead of an evening of Node, Python and config files.

Are my files uploaded anywhere?

No. Everything runs on your computer. There is no account and no telemetry. Only tools whose job is the network — sending a file, uploading to your own Immich server — use it.
