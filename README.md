# GUI Hub

Friendly point-and-click windows for great open-source command-line tools.

**Website and downloads:** https://muttyrab.github.io

This repository hosts the website (the HTML files at the root) and the app's source
(`source/`), from which the installers on the Releases page are built automatically.
The source is published for transparency; it is not open source (all rights reserved).
Each wrapped tool is developed by its own authors under its own license and is downloaded
from its official release page; none of them is affiliated with GUI Hub.
