Send large files between two computers without uploading to the cloud — free

Send files or whole folders of any size to another computer with a short code phrase. End-to-end encrypted, no account, no size limit.

Email has size limits, and cloud drives mean uploading everything, sharing a link and trusting a third party with your files. A direct, encrypted transfer is simpler.

On the sending computer

  1. Open GUI Hub → Send Files → Send files.
  2. Add the files or folders and press Send.
  3. A short code phrase appears (three words). Tell it to the other person.

On the receiving computer

  1. Open GUI Hub → Send Files → Receive.
  2. Type the code phrase, choose a folder and press Receive.

The receiver can also use the croc command-line program or any croc-compatible app.

Is it safe?

Transfers are end-to-end encrypted using the code phrase; the relay server only passes encrypted data along. This tool is free in GUI Hub.

What powers it

croc (MIT), one of the most popular open-source file-transfer tools.
