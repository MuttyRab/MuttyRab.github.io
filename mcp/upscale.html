Real-ESRGAN MCP server

Lets your AI assistant enlarge photos and pictures 4× with AI — sharper, clearer, ready to print — privately on your own computer. It runs the official Real-ESRGAN 0.2.5.0 locally — no API key, no cloud, files never uploaded. Part of GUI Hub Essentials; unofficial, not affiliated with the Real-ESRGAN project.

Install (one line)

npx -y https://guihub.cc/mcp.tgz --product=essentials

Claude Code: claude mcp add gui-hub-essentials -- npx -y https://guihub.cc/mcp.tgz --product=essentials · Claude Desktop: one-file extension (double-click). Other clients (Cursor, VS Code, Windsurf) — add to the MCP config:

{
  "mcpServers": {
    "gui-hub-essentials": {
      "command": "npx",
      "args": [
        "-y",
        "https://guihub.cc/mcp.tgz",
        "--product=essentials"
      ]
    }
  }
}

The Real-ESRGAN binary is downloaded once (the official release, checked by SHA-256) and cached; after that it works offline. Needs Node.js 18+ for npx.

Tools your assistant gets

MCP toolWhat it doesInputs (* required)
upscale_upscaleUpscale/enhance an image on the user's computer 4× with Real-ESRGAN AI (offline): makes small, blurry or low-resolution photos and pictures larger and sharper, e.g. for printing, wallpapers or old photos. Input JPG/PNG/WebP; saves a new image (format from the output file extension). Choose `model` 'anime' for drawings, cartoons and anime art, otherwise 'photo'. Needs a GPU with Vulkan support (most computers from the last ~8 years).input*, model, out*

Things to ask

  • “Upscale the old family photo on my Desktop 4× so I can print it.”

No MCP client? Agents with their own computer

Codex, Manus, OpenClaw and similar agents can call the same tools from a shell:

npx -y https://guihub.cc/cli.tgz run upscale_upscale --input /path/to/input.jpg --out /path/to/output.png
