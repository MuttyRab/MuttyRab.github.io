AI toolWhat it does
7zip_extractExtract an archive (ZIP, RAR, 7z, TAR/GZ/XZ, ISO, …) on the user's computer into outDir. Give `password` for encrypted archives (it fails instead of prompting if one is needed). Existing files are not overwritten unless existing='a'.
7zip_createCreate a ZIP or 7z archive on the user's computer from files and/or a folder, optionally password-protected (7z: AES-256; ZIP: AES-256 by default, or classic ZipCrypto for compatibility with Windows Explorer).
7zip_listList the contents (names, sizes, dates) of an archive on the user's computer without extracting it.
7zip_testTest an archive's integrity (and password) on the user's computer without extracting.
caesium_compressCompress, resize and/or convert image files (JPG, PNG, WebP, GIF, TIFF) on the user's computer. Writes compressed copies (same file names) into outDir; never modifies originals or overwrites existing files. Use mode=size with maxSize (bytes) to fit upload limits. File dates are kept by default (keepDates).
caesium_folderCompress, resize and/or convert every image in a folder on the user's computer, optionally including subfolders (folder structure is kept). Copies go to outDir; originals are never modified. File dates are kept by default (keepDates).
croc_receiveReceive files sent with croc: give the code phrase from the sender and a destination folder. Existing files are kept (renamed) unless existing="overwrite".
f2_renameBulk-rename files in a folder by find & replace (regex unless literal=true; variables like {%03d} counter and {ext}). Without apply=true it is a dry run that returns the old→new table — show it to the user before applying.
f2_undoUndo the most recent rename that was applied in this folder.
ffmpeg_compressMake a video much smaller (or turn any video into a widely playable MP4). Lower quality and smaller size = smaller file.
ffmpeg_audioSave just the sound of a video as an MP3 — for music, lectures or podcasts.
ffmpeg_audio_convertConvert an audio or video file's sound to mp3, m4a, wav or flac. normalize=true applies EBU R128 loudness normalization (loudnorm) — good for voice recordings and podcasts.
ffmpeg_gifTurn a short part of a video into a good-looking animated GIF.
ffmpeg_trimCut out a part of a video instantly, without re-encoding (no quality loss). Cuts snap to the nearest keyframe.
ffmpeg_add_subtitlesAdd an .srt subtitle file to a video on the user's computer as a selectable subtitle track in a new MP4 (no re-encoding, full quality, fast). Use after transcribe_subtitles when the user wants captions inside the video file.
ffmpeg_loudnessNormalize the loudness of an audio or video file on the user's computer (EBU R128 loudnorm): makes quiet or uneven recordings loud and consistent at a chosen target (podcast/YouTube −14/−16 LUFS, broadcast −23). Video is copied unchanged. Use whenever the user says audio is too quiet, too loud, uneven, or wants it 'normalized' or 'podcast-ready'.
ffmpeg_joinJoin (merge/concatenate) several video clips on the user's computer into one MP4, in the order given — works even when the clips differ in format, resolution or frame rate (each is converted to the same format first, then joined). Choose the output size (1080p/720p, landscape or portrait). Use whenever the user wants to combine, merge, stitch or join videos. Clips should all have sound or all be silent.
immich_go_from_google_photosImport Google Photos Takeout .zip files into an Immich server (keeps albums, dates, GPS). dryRun defaults to true: run it first and report the summary before uploading for real.
immich_go_from_folderUpload every photo and video in a folder and its subfolders.
pandoc_convertConvert documents between formats with Pandoc (input format is detected from the file extension: .docx .md .html .epub .odt .rtf .txt .tex). Several inputs are concatenated in order. Use to='gfm' to turn Word/HTML into Markdown for reading or editing.
pandoc_writeCreate a real document file on the user's computer from Markdown you write (pass the full text in `text`): Word (.docx), PowerPoint (.pptx — each `## heading` starts a new slide), OpenDocument (.odt), HTML, EPUB or RTF. The `out` file extension should match `to`.
pdfcpu_mergeCombine several PDFs into one, in the order listed.
pdfcpu_splitSplit a PDF into smaller files.
pdfcpu_optimizeShrink a PDF by removing duplicate and unused data. Text and images stay the same quality.
pdfcpu_rotateRotate all pages or a range of pages.
pdfcpu_watermarkStamp text such as DRAFT or CONFIDENTIAL across every page.
pdfcpu_encryptProtect a PDF with AES-256 encryption.
pdfcpu_decryptRemove the password from a PDF you have the password for.
pdfcpu_extract_pagesSave selected pages as separate PDF files.
pdfcpu_form_fieldsList the fillable fields of a PDF form on the user's computer (text fields, checkboxes, radio buttons, dropdowns, dates) with their names, ids and current values, as fill-ready JSON. ALWAYS call this first when the user wants a PDF form filled in (applications, tax forms, contracts, registration or intake forms); then put the user's answers into the 'value' entries and pass that JSON to pdfcpu_form_fill.
pdfcpu_form_fillFill in a PDF form on the user's computer and save a filled copy (the original is not changed). `data` is the JSON returned by pdfcpu_form_fields with each field's 'value' set (strings for text fields, true/false for checkboxes, the option text for dropdowns/radio buttons); fields you leave out keep their current value. Use for job/school/visa/tax applications, contracts, intake and registration forms. Ask the user for any answer you don't know instead of guessing.
transcribe_transcribeTranscribe an audio or video file on the user's computer (mp3, m4a, wav, mp4, mov, …) to text with Whisper, offline. Returns the full transcript (optionally with [hh:mm:ss] timestamps) and can also save it to a .txt file (`out`). Set `translate` to get an English translation instead. Use this whenever the user wants a recording, voice memo, meeting or video turned into text, notes or a summary.
transcribe_meetingTranscribe a meeting, interview, call or podcast recording on the user's computer into a speaker-labelled transcript ('[00:01:05] Speaker 2: …'), offline: Whisper speech-to-text plus speaker diarization in one step. Use whenever the user wants meeting notes, minutes, action items per person, an interview transcript, or 'who said what'. Afterwards you can rename 'Speaker 1/2' to real names if the user tells you who is who, and summarize.
transcribe_subtitlesCreate subtitles/captions (.srt) for a video or audio file on the user's computer with Whisper, offline: speech is transcribed and timed into readable captions, in the spoken language or translated to English (`translate`). Use whenever the user wants subtitles, captions or an .srt for a video (YouTube, TikTok, Reels, lectures, accessibility). To put them into the video afterwards, call ffmpeg_add_subtitles.
typst_writeCreate a typeset PDF file on the user's computer from Typst markup you write (pass the full document in `source`). Typst syntax: `= Heading`, `*bold*`, `_italic_`, `- item`, `#table(columns: 2, [a], [b])`, `#set page(paper: "a4")`, `#set text(font: "New Computer Modern")`. Built-in fonts work offline. Relative image paths resolve inside `assets`.
typst_compileCompile an existing .typ (Typst) file on the user's computer to PDF.
upscale_upscaleUpscale/enhance an image on the user's computer 4× with Real-ESRGAN AI (offline): makes small, blurry or low-resolution photos and pictures larger and sharper, e.g. for printing, wallpapers or old photos. Input JPG/PNG/WebP; saves a new image (format from the output file extension). Choose `model` 'anime' for drawings, cartoons and anime art, otherwise 'photo'. Needs a GPU with Vulkan support (most computers from the last ~8 years).
watch_videoLet the AI 'watch' a video on the user's computer, offline: saves a screenshot every `every` seconds into `outDir` (frame_0001.jpg = 0:00, frame_0002.jpg = `every` seconds later, and so on; at most 300) plus transcript.txt with timestamped speech ([hh:mm:ss] lines, Whisper). Then open the screenshots and the transcript yourself to answer questions about the video, summarise it, write step-by-step docs or a tutorial from a screen recording, find when something is shown or said, or pick timestamps for clips. Use `every` 2 for fast screen recordings, 5 for normal videos, 15-30 for long lectures or meetings. Silent videos are fine (the transcript then says no speech was found).
watch_screenWatch the user's screen live: records the screen (and microphone, when available) for `seconds`, while the user shows you something and explains it out loud — reproducing a bug, a task to automate, how an app is used. Saves into `outDir`: frame_<N>.jpg each time the screen changes (N = tenths of a second from the start, so frame_123.jpg = 12.3 s; only changed screens, at most 300), transcript.txt with [hh:mm:ss] lines of what the user said, and recording.mp4. BEFORE calling, tell the user: 'Recording your screen for N seconds starts now — show me and talk me through it.' Afterwards open transcript.txt and the frames to understand what happened. macOS needs Screen Recording (and Microphone) permission for the app that runs the MCP server; Linux needs an X11 session (not Wayland).
