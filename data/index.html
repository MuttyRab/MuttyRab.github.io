Tools in GUI Hub Data

Spreadsheet & Data ToolkitDuckDB GUI & MCP server
AI toolWhat it does
duckdb_summarizeInspect a local data file (CSV/TSV, Excel .xlsx, Parquet, JSON) without loading it into the chat: returns the first rows and per-column statistics (type, nulls, min, max, distinct count) as Markdown tables. Use this before writing a query.
duckdb_convertConvert a local data file between CSV, Excel (.xlsx), Parquet and JSON. Writes a new file; the original is not changed.
duckdb_combineCombine several local CSV files into one file (rows stacked, columns matched by name; missing columns become empty). Output format CSV, Excel, Parquet or JSON.
duckdb_dedupeWrite a copy of a local data file with exact duplicate rows removed (CSV, Excel, Parquet or JSON in; chosen format out).
duckdb_queryRun DuckDB SQL over local data files and get the answer as a Markdown table. Read files by quoted path: SELECT * FROM '/abs/path/file.csv' (also .xlsx, .parquet, .json; globs like '/dir/*.csv'). Use for totals, filters, group-bys, joins across files on data too big to paste into chat. Results are capped by the row limit; to save results use COPY (query) TO '/abs/out.xlsx' (FORMAT xlsx, HEADER true).
